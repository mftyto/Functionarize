# PyFunc Studio

<img src="исходники/assets/icons/pyfunc.png" width="96" align="right" alt="Иконка PyFunc Studio">

Нативная Windows-программа для живой визуализации математических функций: графики 2D, поверхности 3D, поля направлений, неявные кривые и параметрические фигуры. Написана на C++20 с Direct3D 11 и Dear ImGui, расширяется скриптами C# через Roslyn.

![3D сцена](исходники/docs/screenshots/3d.png)

## Возможности

- **Семь режимов**: `y = f(x)`, `r = f(θ)`, `x(t), y(t)`, `F(x, y) = 0`, векторное поле, `z = f(x, y)`, параметрическая поверхность `x, y, z(u, v)`.
- **Собственный компилятор выражений** в байткод: выражение разбирается один раз, затем миллионы вычислений за секунды без обхода AST.
- **Многопоточная генерация геометрии** (thread pool, до 24 потоков).
- **Анимация во времени**: переменная `t`, скорость, пауза, перемотка.
- **C# расширения**: скрипты `.csx` из папки `plugins` выполняются в отдельном процессе `PluginHost`, поддерживают горячую перезагрузку по `F5`. Падение скрипта не роняет приложение. Скрипт может объявлять настройки и кнопки действий, которые приложение рисует в панели «C# РАСШИРЕНИЯ».
- **2D и 3D**: сетка, оси, подписи, неявные контуры методом marching squares, каркасный режим, настройка домена и камеры.
- **2D-объекты в 3D**: кривые и контуры 2D-слоёв проецируются на плоскость `z = 0`; переключатель есть в меню «Вид», правой панели и настройках.
- **Сечение 3D-функции на 2D-полотне**: поверхность `z = f(x, y)` проходит сквозь плоскость `z = 0`, а на 2D-полотне отображается ровно та её часть, которая пересекает эту плоскость.
- **Привязка значений к графику**: зажмите `Ctrl` и наведите мышь на кривую в 2D — появится точка привязки и точные координаты `x`, `y`. `Ctrl`+клик закрепляет точку.
- **Экспорт таблиц Excel**: C#-плагины строят `.xlsx` или `.csv` для 2D-функции и для 3D-таблицы. В 3D-режиме можно выбрать пару координат `XY`, `XZ` или `YZ`, а третья вычисляется по формуле.
- **Настройки**: шаг масштаба колесом, зум к курсору, обновление C#, лимит FPS, статистика и точность геометрии; сохраняются в `settings.json`.
- **Проекты** `.pyfunc.json` (сохранение/загрузка) и экспорт PNG.
- **CLI-режим скриншотов** для автоматизации и документации.

## Структура репозитория

```
pyFunc/
├── Билд/                   # результат сборки: PyFunc.exe, PluginHost, plugins, assets
├── исходники/
│   ├── src/                # C++20: Win32, D3D11, ImGui, VM, геометрия
│   ├── extensions/         # C#: PluginApi и PluginHost (Roslyn)
│   ├── plugins/            # примеры расширений .csx
│   ├── assets/fonts/       # Inter + JetBrains Mono
│   ├── assets/icons/       # готовый pyfunc.ico/png и лицензия Icons8
│   ├── third_party/        # ImGui, nlohmann/json, stb_image_write
│   └── CMakeLists.txt
├── build.ps1               # полная сборка C++ и C#
└── run.ps1                 # запуск собранного приложения
```

## Требования

- Windows 10/11 x64.
- Visual Studio 2022 или 2026 с рабочей нагрузкой **«Разработка классических приложений на C++»** (MSVC, Windows SDK) и CMake 3.25+.
- [.NET 10 SDK](https://dotnet.microsoft.com/download) для сборки C# хоста. Для запуска готовой сборки достаточно .NET 10 Runtime.

## Сборка и запуск

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\run.ps1
```

Скрипт сам находит CMake (в PATH или внутри Visual Studio), выбирает генератор `Visual Studio 18 2026` / `Visual Studio 17 2022`, собирает Release в `Билд` и публикует `PluginHost` с ReadyToRun.

Полезные ключи:

```powershell
.\build.ps1 -Clean        # пересоздать дерево CMake
.\build.ps1 -SkipCSharp   # только C++ (если .NET SDK не установлен)
```

Ручная сборка:

```powershell
cmake -S исходники -B Билд\.cmake -G "Visual Studio 18 2026" -A x64
cmake --build Билд\.cmake --config Release --parallel
dotnet publish исходники\extensions\PluginHost\PluginHost.csproj -c Release `
  -r win-x64 --self-contained false -p:PublishReadyToRun=true -o Билд\PluginHost
```

Первый запуск C#-хоста занимает несколько секунд: Roslyn прогревает JIT и компилирует скрипты. Встроенная сцена при этом уже работает — расширения подключаются в фоне.

## Язык выражений

Переменные: `x`, `y`, `z`, `t`, `u`, `v`, `r`, `theta` (или `th`).
Константы: `pi`, `tau`, `e`, `phi`, `inf`.
Операторы: `+ - * / % ^` (`**` тоже степень), сравнения, `&&`, `||`, `!`, тернарный `?:`.
Поддерживается неявное умножение: `2x`, `3sin(x)`, `(x+1)(x-1)`.

Функции: `sin cos tan asin acos atan atan2 sinh cosh tanh asinh acosh atanh exp log ln log10 log2 sqrt cbrt abs floor ceil round trunc fract sign min max pow mod hypot clamp lerp mix smoothstep step if sinc noise fbm rad deg rnd`.

Примеры:

```text
sin(sqrt(x*x + y*y)*2.1 - t*1.7) * exp(-0.055*(x*x + y*y)) * 1.6
0.18*(x*x - y*y) * exp(-0.045*(x*x + y*y))
1 + 0.45*sin(5*theta)
```

## C# расширения

Каждый файл `Билд\plugins\*.csx` автоматически компилируется и выполняется при каждой сборке сцены. Доступен глобальный объект `ctx` (`PluginContext`) и построитель геометрии `ctx.Scene`.

```csharp
double t = ctx.Time;

ctx.Scene.ParametricSurface3D(
    "Тор",
    (u, v) => {
        double r = 2.5 + 0.95 * Math.Cos(v);
        return (r * Math.Cos(u), r * Math.Sin(u), 0.95 * Math.Sin(v));
    },
    uSteps: 120, vSteps: 56,
    color: "#FF8E6BFF", opacity: 0.93f);

ctx.Scene.Polyline2D("Лиссажу", points, "#FF52F2B3", 2.6f);
ctx.Scene.Label2D("подпись", ctx.XMin + 0.35, ctx.YMax - 0.5);
ctx.Log("t = " + t.ToString("F2"));
```

Методы `SceneBuilder`: `Polyline2D`, `Line2D`, `Parametric2D`, `Plot2D`, `Label2D`, `Polyline3D`, `Line3D`, `Mesh3D`, `Surface3D`, `ParametricSurface3D`, `SliceImplicit3D`. Цвета задаются в формате `#AARRGGBB`.

### Настройки и действия плагинов

Скрипт может объявить элементы управления, и приложение само отрисует их в панели «C# РАСШИРЕНИЯ». Значения сохраняются между перезапусками сцены и передаются скрипту при следующей сборке.

```csharp
double size = ctx.Settings.Number("size", 1.5, "Размер", 0.1, 4.0, 0.05);
string formula = ctx.Settings.Text("formula", "sin(x)", "Формула");
bool enabled = ctx.Settings.Bool("enabled", true, "Включено");
string format = ctx.Settings.Choice("format", "xlsx", "Формат", "xlsx", "csv");
string path = ctx.Settings.File("path", "C:\\temp\\table.xlsx", "Файл");
ctx.Settings.Button("export", "Сформировать таблицу");

if (ctx.WasAction("export"))
{
    // Действие выполняется только в ответ на нажатие кнопки.
    ctx.Notify("Готово: " + path);
}
```

![Настройки C#-плагинов и экспорт таблицы](исходники/docs/screenshots/plugins.png)

`F5` перезагружает скрипты без перезапуска приложения. Ошибки компиляции и выполнения показываются в панели «C# РАСШИРЕНИЯ».

### Сечение 3D-функции на 2D-полотне

`SliceImplicit3D` пересекает поле `F(x, y, z) = 0` с плоскостью `z = const` и строит получившиеся кривые на 2D-полотне. Для поверхности `z = f(x, y)` достаточно передать поле `f(x, y) - z`:

```csharp
double f(double x, double y) => Math.Sin(x) * Math.Cos(y) + offset;

ctx.Scene.Surface3D("3D-функция", f, resolution: 112, opacity: 0.62f);
ctx.Scene.SliceImplicit3D(
    "След на 2D-полотне",
    (x, y, z) => f(x, y) - z,
    z: 0.0,
    xMin: -5.0, xMax: 5.0, yMin: -5.0, yMax: 5.0,
    resolution: 190, color: "#FFFF5FA2", width: 3.0f, showIn3D: true);
```

Когда поверхность целиком выше или ниже плоскости, кривых нет — сечение исчезает. Готовый пример: `исходники/plugins/slices.csx`.

### Экспорт таблиц Excel

Плагин `исходники/plugins/excel_export.csx` показывает настраиваемый экспорт:

- формула `f(x)`;
- интервал (`от`, `до`, `шаг`);
- отдельные значения `x` через `;`;
- точность (число знаков после запятой);
- формат `.xlsx` или `.csv`;
- путь к файлу с кнопкой «Обзор».

Для формул в плагинах есть `MathExpression` (поддерживает `x`, `y`, `z`, `t`, `a`, `b`, функции и неявное умножение), а для записи таблиц — `TableExport.Save(...)`, который создаёт настоящий `.xlsx` (OOXML) или CSV с BOM и разделителем `;`.

### Экспорт 3D-таблицы

Плагин `исходники/plugins/surface_export.csx` экспортирует трёхмерную таблицу:

- пара координат `XY`, `XZ` или `YZ`;
- два независимых интервала `a` и `b` со своими шагами;
- формула третьей координаты (например, `sin(a) * cos(b)`);
- точность, формат `.xlsx`/`.csv` и путь к файлу.

Для пары `XY` таблица содержит столбцы `x`, `y`, `z`; для `XZ` — `x`, `z`, `y`; для `YZ` — `y`, `z`, `x`. В формуле доступны как `a`, `b`, так и именованные `x`, `y`, `z`, `t`.

## Настройки и производительность

Меню **Вид → Настройки...** (`Ctrl+,`) открывает общие настройки:

- шаг колеса мыши и масштабирование к курсору;
- обновление C#-плагинов (мс) — увеличение снижает нагрузку на CPU;
- лимит FPS;
- показ статистики;
- точность кривых и контуров;
- видимость 2D-объектов в 3D;
- адаптивное качество при анимации и детализация (40–100%).

Настройки приложения сохраняются в `Билд/settings.json`; параметры точности и видимости входят в проект `.pyfunc.json`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Tab` | переключить 2D / 3D |
| `Space` | пауза / продолжить |
| `Ctrl+N`, `Ctrl+O`, `Ctrl+S` | новый / открыть / сохранить проект |
| `Ctrl+,` | настройки приложения |
| `F5` | перезагрузить C# скрипты |
| `Ctrl` + мышь (2D) | привязка к ближайшей кривой и показ `x`, `y` |

| `Esc` | снять закрепление |

| ПКМ / СКМ | сдвиг камеры |
| Колесо | масштаб (2D) / дистанция камеры (3D) |
| 2×ЛКМ | вписать сцену |

## CLI

```text
PyFunc.exe --screenshot <путь.png> --frames <N> [--2d]
```

Сохраняет кадр после `N` кадров и завершается. Используется для скриншотов и регрессионных проверок.

## Производительность

- Геометрия поверхности строится в пуле потоков; при анимации адаптивное качество снижает разрешение до выбранной детализации (по умолчанию 65%). На демо-сцене это даёт около 10 мс на кадр и стабильные 60 FPS; пауза возвращает полное разрешение.
- Нормали высотных и параметрических поверхностей вычисляются аналитически по сетке, без накопления по треугольникам.
- Статичные 2D-слои кэшируются: при обновлении плагинов и анимации соседних слоёв они не пересчитываются заново.
- Обновление C# не перестраивает 3D-геометрию, если видимая геометрия плагинов не изменилась.
- Выражения компилируются в компактные инструкции, вычисление — стековая VM с ветвлением по opcode.
- 3D-рендер: Direct3D 11, MSAA, динамические вершинные/индексные буферы, освещение по нормалям.
- 2D-линии рисуются геометрическим шейдером с толщиной в пикселях.
- Разрешение поверхностей и точность кривых настраиваются в правой панели; интервал C# и лимит FPS — в настройках.
